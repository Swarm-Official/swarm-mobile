# SWARM Wallet App Store art

The existing SWARM artwork is the source of truth. The SVGs in `logo/` are
exact copies of `assets/img/swarm-mark.svg` and
`ios/branding/swarm-appicon.svg`. The PNGs render those SVGs. The mark and
icon design were not changed.

## Deliverables

- `logo/swarm-app-icon-1024.png` is the opaque 1024 × 1024 App Store icon.
- `logo/swarm-app-icon-512.png` is a smaller review export.
- `logo/swarm-mark-1024.png` and `logo/swarm-mark-512.png` preserve transparency.
- `store/ios/icon-1024.png` is the same App Store icon in the store kit.
- `fastlane/metadata/en-US/` contains the App Store name, subtitle, promotional
  text, description, keywords, release notes, and URLs.
- `captures/` contains the four original 1206 × 2622 iPhone simulator captures
  of Receive, Send, History, and Settings.
- `fastlane/screenshots/en-US/` contains four 1320 × 2868 App Store layouts
  with iPhone mockups made from those captures. `review/current-ios-listing.png`
  shows the set.
- `swarm-ios-app-store-kit.zip` packages the screenshots, logo exports, source
  captures, listing copy, and this guide.

## Capture provenance

The captures came from the running `green.swarm.swarmwallet` app on the
`swarm-ios-debug` iOS 18.3 simulator on 24 September 2026. The wallet had
finished syncing. The displayed address belongs to this disposable simulator
wallet. To capture Settings, its `settingsScreen` authentication preference was
temporarily disabled in that simulator's `Documents/settings.json`; no app code
or release default was changed. The app was in Advanced mode for the Settings
capture. Send and History show the app's real empty-wallet state and masked
balance. No transaction data or UI was fabricated.

To regenerate the layouts from the saved source captures:

```sh
python scripts/store/build_store_art.py --preset ios69 \
  --raw design/app-store/captures --out fastlane/screenshots/en-US
node scripts/store/check_store_art.mjs --store ios
```

The composer uses the real capture pixels and the app's Sora and Manrope fonts.
Its `ios69` preset exports the 1320 × 2868 iPhone size. The screenshot manifest
in `scripts/store/screens.json` contains the final captions and order. The
iPhone frames are generated by `scripts/store/build_store_art.py`. The
background graph and halo use `#F5A623` and `#E8890C` from the existing
`ios/branding/swarm-appicon.svg` artwork. Use `--style card` to render the old
flat layout if needed.

## Review notes

- The Send amount field still uses a legacy Z-shaped currency glyph while the
  rest of the screen says SWM. The screenshot reproduces the shipped UI.
- This simulator wallet has no transactions, so History shows the true empty
  state. Replace this capture after a real, safe test transaction if transaction
  detail is important for the listing.
- The wallet privacy policy is published at `https://swarm.green/wallet/privacy`.
  The App Store draft points to this page.

## App Store draft

All four approved layouts, including the revised top captions, finished Apple
processing on 24 September 2026. The listing description, subtitle, promotional
text and keywords describe SWARM Wallet for iPhone. The image files preserve
the approved simulator captures. The Send capture includes its original
network placeholder. Public release requires a matching production build.
